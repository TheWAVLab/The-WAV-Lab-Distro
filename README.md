# The WAV Lab Distro

Official downloads for software by **[The WAV Lab](https://thewavlab.com)** (Sounds Like Joe LLC).

This repository holds **installers only**. Each product's files are attached to a
release tagged `<product>-v<version>`; see **[Releases](../../releases)**.

## Fractus Granular Processor

A granular processor plug-in: VST3 and AAX for Windows and macOS, plus Audio Unit on macOS.
The same installer is used for the 14-day trial and the full version.

- Product page, trial and purchase: https://thewavlab.com/product/fractus/
- macOS 12 or later, Apple Silicon only · Windows 10 or later, 64-bit
- Installers are signed (Apple Developer ID and notarized on macOS; Sounds Like Joe LLC on Windows)

## Patch Cable

Free virtual audio cables and per-app audio routing for macOS: create virtual audio devices,
route apps, system audio and inputs into them, and monitor them on your speakers or headphones.

- Free · public beta
- macOS 14.4 or later, Apple Silicon and Intel
- Installer is signed and notarized (Apple Developer ID)
- Downloads: releases tagged `patchcable-v<version>`
